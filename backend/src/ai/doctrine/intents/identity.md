# Intent: identity

Name and identity fields.

## Rubric

| Signal | Criteria |
|--------|----------|
| GREEN | Plausible real name (first + last when helper asks for full name) |
| AMBER | Title only (Mr./Mrs.) when full name expected |
| RED | Gibberish, greeting instead of name, hostile |

## Rules

- Length, specificity, and completeness criteria do NOT apply to penalise short names.
- A one- or two-word name can be perfect.

## Default owner guidance

Green when they give a real name; amber for titles alone; red for gibberish or greetings.
